# python-dailybible-backend
### Backend for the daily bible automated message system

This is a simple Python-based backend for my automated daily bible messaging system

## Bring your own bible in plaintext to pull data from
This is the formatting the program is designed to pull from:

`Gen 1:1 In the beginning God created the heavens and the earth. `

longer verses can take up multiple lines, just include one blank line in between each verse

for example:

`Gen 1:1 In the beginning God created the heavens and the earth. `

`(empty line)`

`Gen 1:2 The earth was empty, a formless mass cloaked in darkness. And the Spirit of God was hovering over 
its surface. `
